Status: COMPLETE
Priority: HIGH
Estimated Effort: Medium
Created: 2026-04-20
Code: E06S07T114

Upstream: UXR-008 – Default board naming adoption

Coordinates: E02:S16:T03 (UKW perpetual), E06:S07:T110
