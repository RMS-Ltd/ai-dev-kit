## Context

[FR-066](../../project-management/kanban/fr-br/FR-066-docusaurus-canonical-docs-path-and-publish-scope.md) wired the docs plugin to `../docs` with **nearly all** markdown published (changelog-archive excluded only). Maintainer corpora (Kanban, IPPs, architecture ADRs) shared the same strict build gate as adopter guides, causing CI churn ([FR-114](../../project-management/kanban/fr-br/FR-114-split-documentation-surfaces-docusaurus-public-notion-maintainer-kb.md)).

Docusaurus docs plugin has **no native include-only mode** for a subdirectory of a large tree.

---

## Decision

Adopt an **inverse allowlist** — keep `docs.path: '../docs'` and expand **`exclude` globs** in [`portal/docusaurus.config.js`](https://github.com/RMS-Ltd/ai-dev-kit/blob/main/portal/docusaurus.config.js).

### Included (published)

| Path | Rationale |
| ---- | --------- |
| `docs/guides/**` | Adopter workflow and adoption guides |
| `docs/documentation/**` | Adopter user + reference docs (RF7 audit: full tree retained; maintainer-only pages may be excluded in follow-on) |
| `docs/developer-tools/ide-whitelist-guide.md` | Single promoted adopter-facing tool page |
| `docs/documentation/docusaurus-portal-index.md` | Portal entry (`sidebar_position: 0`) |

### Excluded (not published)

| Glob | Rationale |
| ---- | --------- |
| `project-management/**` | Kanban, FR/BR |
| `implementation-cycles/**` | IPPs |
| `maintenance/**`, `analysis/**`, `knowledge/**`, `journals/**` | Maintainer corpora |
| `architecture/**`, `governance/**` | Internal standards |
| `changelog-and-release-notes/**` | RC=0: GitHub only |
| `release-notes/**` | Git-only policy stub (alternative location documented; not published pre-RC) |
| `book-project/**` | Private book spin-off |
| `developer-tools/ide-whitelist-uat-log.md` | Maintainer UAT log |
| Root agent manifest files | Not adopter-facing |

### Sidebar IA

[`portal/sidebars.js`](https://github.com/RMS-Ltd/ai-dev-kit/blob/main/portal/sidebars.js) lists **Guides**, **Documentation** (autogenerated), and explicit **IDE command whitelist** doc only.

### Internal standards linking

From allowlisted markdown, references to excluded trees **must** use GitHub blob URLs (`https://github.com/RMS-Ltd/ai-dev-kit/blob/main/...`), not relative paths — enforced by strict `onBrokenLinks` / `onBrokenMarkdownLinks` / `onBrokenAnchors` and [`tests/test_portal_fr114_allowlist.py`](https://github.com/RMS-Ltd/ai-dev-kit/blob/main/tests/test_portal_fr114_allowlist.py).

### CI path filters

[`.github/workflows/docusaurus-build.yml`](https://github.com/RMS-Ltd/ai-dev-kit/blob/main/.github/workflows/docusaurus-build.yml) triggers on `portal/**`, allowlisted `docs/guides/**`, `docs/documentation/**`, `docs/developer-tools/ide-whitelist-guide.md` — not bare `docs/**` (FR-114-NF1).

### RC ≥ 1 release notes

- **Primary scaffold:** [`portal/blog/`](https://github.com/RMS-Ltd/ai-dev-kit/tree/main/portal/blog/) + [`RELEASE-NOTES-POLICY.md`](https://github.com/RMS-Ltd/ai-dev-kit/blob/main/portal/blog/RELEASE-NOTES-POLICY.md)
- **Alternative (git-only policy stub):** [`docs/release-notes/README.md`](https://github.com/RMS-Ltd/ai-dev-kit/blob/main/docs/release-notes/README.md) — excluded from portal build; documents optional docs-plugin category for RC ≥ 1

No raw `CHANGELOG.md` on the portal during RC=0.

---

## Consequences

- Maintainer edits to excluded trees no longer gate Docusaurus CI on PRs.
- Allowlisted corpus must keep BR-068 discipline (blob URLs for out-of-tree targets).
- FR-066 **publish breadth** is superseded; FR-066 **canonical path** (`../docs`) remains valid.

---

## Alternatives considered

| Option | Rejected because |
| ------ | ---------------- |
| Staging mirror directory | Duplicate corpus maintenance |
| Multiple docs plugins with `include` | Higher config complexity; harder test parity |
| Keep FR-066 breadth + fix links only | Does not reduce CI churn or audience mismatch |
