Significant release notes policy (RC ≥ 1)

June 10, 2026 · One min read

Status: Scaffold — no curated posts until first RC public milestone.
Authority: FR-114 (F6) · E05:S09:T15

Rules​

  • RC = 0 (development): Release history stays on GitHub (CHANGELOG.md, archive) only.
  • RC ≥ 1: Publish narrative milestone posts here (portal/blog/) for significant public releases — not raw Keep-a-Changelog dumps.
  • Each post: SemVer tag, adopter-facing summary, breaking changes, migration pointers.

Template (when authoring)​

Create portal/blog/YYYY-MM-DD-<slug>/index.md with frontmatter (slug, title, authors, tags) per existing blog posts.
