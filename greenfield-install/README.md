# AI Dev Kit — lean adopter install tree (FR-110)

**Vendor or copy this directory** into your project (e.g. `vendor/ai-dev-kit/`). It contains **only** framework packages (~11 MiB) — not the full maintainer repository.

## Quick start

From your **host project root** (parent of this vendor tree):

```bash
python3 "vendor/ai-dev-kit/packages/frameworks/workflow-mgt/scripts/install_greenfield_path.py" \
  --project-root "." \
  --non-interactive
```

Adjust `vendor/ai-dev-kit/` to match your layout. Install scripts live under `packages/frameworks/*/scripts/`.

## Download integrity (SHA-256)

Release tarballs ship with a matching `.sha256` sidecar on [GitHub Releases](https://github.com/RMS-Ltd/ai-dev-kit/releases). Verify before extract:

```bash
gh release download v0.4.1203 --repo RMS-Ltd/ai-dev-kit \
  -p 'greenfield-install-v0.4.1203.tar.gz' \
  -p 'greenfield-install-v0.4.1203.tar.gz.sha256' -D /tmp/adk-dl
shasum -a 256 -c /tmp/adk-dl/greenfield-install-v0.4.1203.tar.gz.sha256
# Expected: greenfield-install-v0.4.1203.tar.gz: OK
```

Pin the SHA-256 from `greenfield-install-v0.4.1203.tar.gz.sha256` (release sidecar).

## Update upstream

- **Submodule / sparse checkout:** `cd vendor/ai-dev-kit && git fetch --tags && git checkout tags/v0.4.1203` (see [releases](https://github.com/RMS-Ltd/ai-dev-kit/releases)).
- **Copy refresh:** re-copy this tree from a tagged `greenfield-install/` export or verified `greenfield-install-v0.4.1203.tar.gz` on [releases](https://github.com/RMS-Ltd/ai-dev-kit/releases).
- **GitHub Container Registry (alternate):** when submodules are blocked, pull the lean image and copy `/opt/adk/` into `vendor/ai-dev-kit/` (same bytes as this tree; [ADR-021](https://github.com/RMS-Ltd/ai-dev-kit/blob/main/docs/architecture/standards-and-adrs/ADR-021-greenfield-install-ghcr-delivery-channel.md)):

  ```bash
  # Replace v0.4.1203 with the external SemVer core you are pinning.
  docker pull ghcr.io/rms-ltd/ai-dev-kit-greenfield:v0.4.1203
  mkdir -p vendor/ai-dev-kit
  cid=$(docker create ghcr.io/rms-ltd/ai-dev-kit-greenfield:v0.4.1203)
  docker cp "$cid:/opt/adk/." vendor/ai-dev-kit/
  docker rm "$cid"
  ```

  Optional digest pin: `docker pull ghcr.io/rms-ltd/ai-dev-kit-greenfield@sha256:<digest>` (see [Packages](https://github.com/RMS-Ltd/ai-dev-kit/pkgs/container/ai-dev-kit-greenfield)).
