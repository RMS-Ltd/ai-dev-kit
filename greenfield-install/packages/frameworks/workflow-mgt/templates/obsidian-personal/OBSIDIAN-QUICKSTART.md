# Obsidian quick start (personal profile)

This repository uses the **obsidian-personal** maintainer editor profile. Git remains the authoritative source for all maintainer documentation.

## Open the vault

1. Install [Obsidian](https://obsidian.md/).
2. Choose **Open folder as vault** and select this repository root.
3. Edit markdown under `docs/knowledge/`, `docs/maintenance/`, `docs/analysis/`, and other git paths as usual.

## Git policy

- Your local `.obsidian/` folder is **gitignored** — workspace layout and plugins stay on your machine only.
- Commit content changes through normal git workflow (PRs, RW releases).
